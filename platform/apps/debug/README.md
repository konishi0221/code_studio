# Debug Launcher (`/debug/`)

開発・運営側の内部用ランチャー。

> このパスはプロダクトの一部ではなく、**オーナーが内部のミニアプリ (help 等) にアクセスするための入り口**。
> エンドユーザー向けの導線は `/` (LP) → `/wizard/` 側にある。

## 使い方
- `/debug/` を開く → Google でサインイン → ミニアプリのグリッドが出る
- グリッドから wizard プレビューや help (Gemini チャット) にジャンプ

## ファイル構成
- `index.html` — Firebase Auth + ミニアプリ一覧 (旧 `apps/index.html` の中身)

## なぜここに切り出したか
- 以前は `/` がランチャーだったが、claude-studio はエンドユーザーが GCP セットアップする SaaS。`/` は LP であるべき、ランチャー的なものは内部用に隔離。
- 既存の `apps/help/` 等は最終的には別リポジトリ (ユーザー側で clone するテンプレ) に移動予定だが、それまでの開発用として `/debug/` 経由で残す。
