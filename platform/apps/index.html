How it works

セットアップの流れ

1

Google ログイン あなた

普段使っている Google アカウントでサインイン。GCP プロジェクトを作る権限をリクエストします。

2

GitHub 連携 あなた

テンプレリポジトリをあなたの GitHub に fork。1 タップで完了。

3

かんたんな質問に回答 あなた

スキルレベル・何を作りたいか・業界 を数クリックで選択。これが Claude Code と AI ヘルプの応答に効きます。

4

裏で全部やる 自動

API 有効化・Cloud SQL 作成・Service Account・Secret・Cloud Build トリガ・初回デプロイまで一気通貫。

5

完了 → あなたの URL 自動

5〜10 分後、あなた専用の https://<your-project>.web.app が稼働開始。
