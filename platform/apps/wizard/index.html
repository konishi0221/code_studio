あなたの Google アカウントで GCP プロジェクトを 1 つ用意するだけ。

construction
実装中 下のステップは設計図。実際の自動セットアップはまだ動きません。 今は platform/infra/bootstrap.sh を Cloud Shell で手動実行する方法しかありません。
Wizard がやってくれる予定の流れ
1
Google アカウントでサインイン
GCP プロジェクトを操作する権限をリクエスト (cloud-platform / billing スコープ)
2
GCP プロジェクトを選ぶ / 作る
既存プロジェクト + 請求アカウントを選択、または新規作成
3
セットアップ情報を入力
プロジェクト名・リージョン (デフォルト asia-northeast1)・最初に欲しいアプリの種類
4
GitHub リポを準備
テンプレを fork、Cloud Build と GitHub を 1 タップ接続
⚠️ GitHub OAuth はブラウザでの手動承認が必要
5
バックエンドで自動プロビジョン
APIs 有効化・Cloud SQL・Storage・SA・Secret Manager・Firebase Auth・Hosting site・Cloud Build トリガを順に作成
所要 3-5 分、回線切れても進む (Cloud Tasks chain)
6
完了 → 自分の URL がもらえる
https://<your-project>.web.app で自分のミニアプリ基盤が稼働開始
