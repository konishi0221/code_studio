# メモ (`/memo/`)

クライアント側 localStorage に保存するだけのシンプルなメモ帳。バックエンド不要。

## 使い方
- 「アプリ」一覧から「メモ」をタップ
- テキストエリアに書く → 入力するたびに保存
- リロードしても残る

## ファイル構成
- `index.html` — UI + ロジック (1 ファイル完結)

## なぜ含まれてるか
バックエンド無しでも動くアプリの最小サンプル。Cloud SQL 等オプションを選ばなくても、wizard が作る user のスタックには常に含まれる (`app.yaml` に `REQUIRES_OPTIONS` を書かない = 常時 include)。
